 # Sistema de Ventas de Computadoras

Sistema web desarrollado venta de computadoras, laptops y accesorios.

## Tecnologías

- Python
- Flask
- MySQL
- Bootstrap

## Ejecución

```bash
pip install -r requirements.txt
python app.py
```
en Visual Studio Code

## Base de Datos

Importar el archivo:

```text
tiendaBD.sql
```

en phpMyAdmin.


## Manual de Usuario

- Registrarse.
- Iniciar sesión.
- Ver productos.
- Agregar al carrito.
- Realizar pedidos.
